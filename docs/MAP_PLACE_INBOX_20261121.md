# 場所未登録の記録一覧と初回登録ガイド

日本酒マップの左上に地図＋アイコンを追加。写真付きの保存酒とメニュー履歴から、有効な座標付きの飲んだ場所がない記録を抽出し、赤バッジに件数を表示する。酒瓶は保存IDごと、メニューは履歴IDごとに1件。メニュー内の商品数はバッジに加算しない。場所の文字入力だけがある旧記録は店舗選択で補完できるよう残す。

一覧の行または黄色の「場所を登録」から既存PlacePickerを開く。酒瓶は保存成功を確認してからUIを更新し、ログイン時は既存の保存同期を使用する。メニューは既存setHistoryPlaceと永続outboxを使用する。登録済みのものは一覧とバッジから外れる。マップに戻る際はメニュー同期と地図再取得を行う。ゲストは既存仕様に沿って端末内へ保存する。サーバー反映/自分の店舗マップは既存の認証・同期条件に従う。

「覚えていない」は写真・保存酒・メニュー履歴の削除ではなく、案内からの除外。Snackbarの「元に戻す」で復元できる。除外IDはアカウント別（ゲストを含む）・端末内に保存し、連続操作を直列化する。他端末へ除外設定を同期する変更は含まない。場所の登録には有効な座標が必要で、手入力の店名のみを地図表示できたとは扱わない。

ホーム/メニュー/マップのメニュー履歴は同じアカウント単位のNotifierを共有する。独立した撮影ルートから戻ったときとホーム/マップへのタブ切替時には履歴を再読込。詳細から単独で開くマップにも履歴Providerを用意した。アカウント変更後の古い一覧は表示せず、選択中にアカウントが変わった場合は保存しない。写真・感想・公開設定等を保持する。

## 進行ガイド

最新mainから抜けていた195番の好みガイドを、当該機能のコード・達成フック・関連テストに限って復元した。OCR候補シートなど別ブランチの変更を一括統合していない。

既存4段階（好み・いいね・診断・解析）の進捗に「はじめの1件を地図に残す（任意）」を追加。任意項目は4段階の完了を妨げず、既存の完了履歴・7日延期・永久非表示・アカウント分離・チュートリアル中の抑止を維持。座標付きの場所が保存酒かメニューに1件あれば、任意項目は登録済みになる。「覚えていない」は達成として数えない。

案内から未登録一覧へ進める。好みガイドの既存アクションも復元し、おすすめレールが画面外でも既存のスクロール処理で移動する。診断条件は画面/Notifier共通でいいね2件。
