# 未保存の商品から同じ銘柄を選び直す

## 原因と変更

報告された「KURAMOTO 64 露葉風 BODAIMOTO Light」は本番商品6913、銘柄KURAMOTO3942、蔵元は倉本酒造株式会社に正しく紐づいている。
本番の同銘柄候補APIでも11件を取得し、全件が銘柄3942で現在の商品を含まないことを確認した。

三点メニューの再選択項目だけが、銘柄情報ではなく個人の保存記録の有無で表示を制限していた。この条件を外し、未保存の商品でも「同じ銘柄から選び直す」を表示するよう修正した。旧ラベルの「同じ酒蔵から再選択」も実際の検索範囲である銘柄に合わせた。

- 未保存: 選んだ商品の詳細を開く。保存記録は作成せず、既存記録も移管しない。
- 保存済み: 従来の再選択処理を使い、写真・場所・個人評価・メモを元の保存IDのまま引き継ぐ。
- 候補一覧は下部の同銘柄セクションと同じページ付きAPIから全ページ取得する。概要内の候補だけに依存せず、現在の商品と重複IDを除外する。旧リポジトリは既存の概要内候補へフォールバックする。
- 通信エラーは「候補がない」と区別して案内し、メニューを再度操作して取得し直せる。ページを閉じてから選択画面を開かない。
