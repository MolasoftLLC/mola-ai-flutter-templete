# 酒印帳の県境ページ送りと表紙へ戻る操作

未配信（配信済み175には含まれない）。

専用酒印帳で、選択県の最終ページを次へ送ると、県ID順の次県へ移動。紙面の右矢印と左スワイプの両方に対応し、全国→北海道、沖縄→全国の既存の順番を使う。追加銘柄の取得中・失敗・未取得ページがある場合は次県へ飛ばさない。

先頭ページの左矢印・右スワイプで表紙へ戻れる。どのページからでも使える「表紙に戻る」も配置。表紙は閉じるアニメーションを行い、再度開ける。閉じている間の裏側の誤タップを抑止し、再度開くとそれまでの県・ページ位置を維持する。

ホームプレビュー・地図側の既存カタログには県境操作を追加していない。取得条件・記録データ・同期処理は変更なし。

検証: 関連36件成功（県境矢印、スワイプ確定／取消、表紙を閉じ再度開く、追加ページ取得失敗・再試行を含む）。静的解析は既存418件、新規エラーなし。iOS実機検証・配信は未実施。
