# 日本酒瓶の補助枠と表示サイズの調整

2026-10-29の配信作業中の追加依頼。「先に日本酒の形へ」「画面全体に近い補助枠にして、小さく撮らないように」に対応。

- 正面撮影のガイドを、短いキャップ・細い首・なだらかな肩・長い胴の日本酒瓶に近い輪郭へ変更。
- ガイド領域の縦横比を0.50から0.34へ変更。上から下へ大きく使うよう余白を見直し、390×844の画面では撮影エリア766ptに対してガイド高さ626pt（約82%）。従来は464pt（約61%）だった。
- 下部はフローティング操作ボタンの背後までガイドを伸ばす。ガイドのIgnorePointerを維持し、シャッター・写真選択・補助枠切替の操作を妨げない。
- 文字拡大時は上部の案内に合わせて余白を増やし、キャップと文章の重なりを避ける。
- 「瓶を枠に合わせ、ラベルが大きく写る距離で撮影してください。」と案内を更新（英語も対応）。
- 裏ラベル・メニューの四角い枠は従来の寸法を維持。
- 補助枠は表示のみ。撮影画像の自動切り抜き、撮影の倍率、解析処理は変更しない。

## 参照写真に基づく輪郭の描き直し（配信162の後）

ユーザーから追加の瓶写真と「日本酒の形ではない、よく観察して」との指摘。162の輪郭は肩が上部で急に広がり、その下が長い直線になる形だったため、参照写真の輪郭へ修正。

- 縦長のキャップ、その下の細い首、瓶の中央から下まで続く長い曲線を再現。
- 首と肩、肩と胴の接線が連続する曲線へ変更。まっすぐな胴は下側約3割のみ。
- 写真の瓶の最大幅/高さは概ね0.26。描画領域の比率を0.30にし、実際の輪郭の幅/高さを約0.26へ調整。
- 枠の高さ・上下余白・表示切替・裏ラベル/メニューガイドの挙動は維持。
- 既存のカメラ画面2テスト成功、変更ファイルのanalyzeは指摘0。標準画面と320×568・文字1.5倍の描画を目視確認。
- この修正はアップロード済み162には含まれない。この時点では新しいビルドの作成・配信は行っていない。
