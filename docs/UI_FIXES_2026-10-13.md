# 詳細・タイムライン・メニュー履歴・マイページの修正

## 変更点

- 記録編集シートはキーボードの高さを避け、感想欄をスクロールできるようにした。
- 記録編集、タイムライン共有、ラベル解析の感想欄は欄外タップでもキーボードを閉じる。
- 保存画像はAPIの `imageUrls` を正とし、解析JSONに残った削除済み画像を復元しない。明示的な空配列も反映する。未同期の端末写真は保持する。
- 写真追加後はサーバーの画像一覧へ同期する。同期済みの1枚目に端末パスが残っている場合は記録編集前にも同期し、サーバーへ削除要求を送れるようにした。古い端末パスしか特定できない場合に削除成功とは扱わない。
- 店舗マップの読み込み表示を中央に配置した。
- ブラウザ検索はユーザーの希望に合わせて `externalApplication` を使い、端末の外部リンク設定に従う。Safariには固定しない。Universal LinkとしてGoogleアプリに関連付けられている場合はOSがGoogleアプリを選ぶ場合もある。
- みんな／自分のタイムラインは更新アイコンを読み込み表示へ切り替え、二重更新を防ぐ。
- 商品IDがないタイムライン投稿もタップできるようにし、酒名を入力済みの候補検索へ進む。他人の保存記録を変更する処理は呼ばない。
- メニュー履歴の外側の開閉状態はローカル状態で管理する。個別結果には独立したPageStorageを設け、横スクロール位置の保存を無効にしてboolとdoubleの衝突を防ぐ。
- 設定シートの下部に余白とSafeAreaを追加し、小さな画面ではスクロールできるようにした。
- 保存酒の並び替えはタグがなくても利用でき、新しい順／古い順／マッチ度順を選べる。タグ絞り込みは同じメニュー内に残す。

## 実機で確認する操作

1. 詳細→あなたの記録を編集→感想欄で入力し、最終行とカーソルがキーボードより上に見えること、欄外タップで閉じることを確認。
2. 思い出写真を2枚追加し、1枚目を拡大→削除。残った写真が1枚で、記録を保存／開き直し／更新しても削除した写真が戻らないことを確認。最後の1枚の削除、ゲストの場合も確認。
3. 詳細→近くで飲める場所を探す、で読み込み表示が中央に出ることを確認。
4. 詳細→タイムライン共有の公開コメント、ラベル解析の感想欄で欄外タップによるキーボードの解除を確認。
5. Safari／Chrome等をデフォルトに設定したiPhoneで詳細→この名前でブラウザで検索、の起動先を確認。GoogleアプリへのUniversal Linkの関連付けも確認。
6. みんな／自分のタイムラインで更新ボタンが読み込み中になり、終了時に戻ることを確認。商品IDありの投稿は詳細、IDなしは名前の候補検索に進むことを確認。
7. 複数のメニュー履歴を開閉し、各日本酒の詳細開閉とタグの横スクロール、画面往復を繰り返してもグレー表示にならないことを確認。
8. マイページの設定でキャンセルの下に余白があること、保存酒にタグがなくても並び替えを開けること、各順序とタグ絞り込みの併用を確認。
