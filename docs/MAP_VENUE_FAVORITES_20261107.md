# 日本酒マップ：お店のお気に入り

店の詳細右上に星を追加。保存した店は日本酒マップ右上の星から一覧表示でき、一覧の店名/「日本酒マップで見る」で位置へ移動して店の日本酒詳細を開く。「Googleマップ」からは保存した座標とGoogle Place IDで外部地図を開く。位置情報を許可していない場合も保存済み座標で利用できる。

お気に入りはSharedPreferencesへ端末内保存し、ページを閉じたりアプリを再起動しても復元。ゲストと各ログインユーザーの保存先は分離。現段階では端末間クラウド同期・ゲストからログインへの自動移行は行わない。個人の履歴/投稿は保存対象に含めない。

保存完了後に星を更新し、連打を防止。保存失敗時は既存の星を維持してエラー表示。読込失敗を空一覧と扱って上書きしない。アカウント切替時は一覧を即座にクリアし、古い読込/保存結果を新しいアカウントに表示しない。

お気に入りへの移動時には酒名検索・「自分の登録」を解除し、古い通信結果を無効化。地図初期化前の選択も保留して初期化後に保存座標へ移動する。店舗の提供酒リスト/メニュー写真は既存APIから取得する。
