# 同銘柄の商品再選択を自分の保存記録に戻す

## 変更

ユーザーの依頼により、build 153で広げた未保存商品からの「同じ銘柄から選び直す」を取り消した。現在の利用者の保存一覧に対象商品がある場合だけ表示し、操作後はその利用者自身の保存記録を付け替える。

- 三点メニューの表示と操作分岐の両方で、自分の保存記録を必要とする。
- 保存記録なしで別商品の詳細を開く再選択経路を削除した。
- 自分の記録では、同銘柄候補の全ページ取得と、保存ID・写真・場所・評価・メモの保全を維持する。
- サーバーは認証済み利用者IDと保存IDを合わせて照合し、他の利用者の記録は変更できない。サーバーの権限を緩める変更はない。
- 他の利用者の投稿の修正は今後adminの権限を持つ利用者向けに実装する。今回admin用の他人の記録修正機能は追加していない。

## 検証

- 関連操作テスト4件が成功。未保存では項目が表示されないこと、自分の保存記録の付け替えで個人情報が保持されること、候補取得失敗後の再試行、候補0件を確認。
