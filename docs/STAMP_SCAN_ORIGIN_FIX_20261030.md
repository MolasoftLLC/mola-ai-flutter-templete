# 詳細閲覧だけで酒印が付く問題の修正

5.0.43（173）では、詳細の解析完了判定だけで酒印を付けていたため、他人のタイムライン投稿・検索・商品一覧から詳細を開いても取得できた。

ラベル解析の候補確定後に開く詳細だけに対象商品IDを渡し、取得対象と一致し、詳細解析も成功している時だけ酒印を付与する。通常閲覧では対象IDを渡さない。詳細画面と付与処理の両方で判定するため、同じ銘柄の別商品へ移動しても権利は引き継がれない。自分の記録保存からの付与は継続する。

## 検証
- 付与・未解析・非対象商品・アカウント切替・画面離脱など11件成功。
- 通常閲覧では未付与、自分のラベル解析では付与、再表示では重複しない画面テスト1件成功。
- 静的解析は既存418件、新規エラーなし。

## 既存データ
旧版の analyzed_detail には閲覧経路が保存されておらず、正しい撮影取得と誤付与をこの値だけで区別できない。既存の端末内・同期済み酒印は削除していない。サーバー変更・アプリ配信はこの修正時点では未実施。
