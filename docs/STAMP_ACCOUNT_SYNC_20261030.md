# ご酒印のアカウント同期と利用計測

- 既存のアカウント別端末保存をそのまま読み、起動／ログイン後、取得後、アプリ復帰時にクラウドと取得済み銘柄を統合する。端末保存を先に確定し、失敗時は保持して再送。未解決の商品も端末から削除しない。
- 別端末で同じアカウントへログインするとクラウドから復元する。復元時は獲得演出を再生しない。ゲスト保存は別領域で維持し、ログインアカウントへ推測で結合しない。
- 旧端末の取得済み分は対応版を旧端末で開いて同期する必要がある。同期前に消失した端末データは復旧対象外。
- 認証UIDを送信前、トークン更新後、レスポンス受信時に確認。アカウント切り替え中のレスポンスを別人の保存へ混ぜない。削除完了後は端末キャッシュを消し、再同期を停止する。
- 計測は受理／拒否IDを見てキューを更新する。旧サーバーの400は1件ずつ分離し、有効な隣接イベントを残す。拒否分は端末の診断用領域に最大50件保持する。
- 酒印取得は新規付与の保存成功のみ。復元、既存記録継承、デモは計上しない。schemaVersion 3で対応版を区別する。

## 確認

32件の関連テスト成功。アプリ全体の解析は既存の指摘のみ（変更ファイルの追加指摘なし）。バックエンドは本番反映済みで、保存・取得・再送・分離のロールバック検証、計測HTTPの2件受理／1件拒否、公開ヘルス200を確認。詳細はbackendの `docs/SAKE_STAMP_SYNC_AND_USAGE_20261030.md`。
