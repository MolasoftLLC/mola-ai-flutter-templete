# iOS 5.0.59（198）限定リリース

## 公開版からの差分

ユーザー指定で公開中の5.0.52（188）を基準とする。App Store Connectで公開版に紐付くbuild188とpreReleaseVersion 5.0.52を照合済み。基準コミット `01ef62e`。App Store側の掲載バージョン名5.1.1とは区別する。

追加は次の5項目だけ。
- マップ左上の未登録一覧（酒瓶・メニューの場所を一覧から登録、覚えていない・取消）
- 未登録件数の赤バッジ
- 店舗の星リストと分かりやすい入口
- タイムラインの「もっと見る」に好みの一致率％
- Yahoo!購入リンクのValueCommerce対応と購入欄の広告表示（サーバーPR74）

ホームの次のアクション案内・進行バー・場所登録の初回ステップ、通知/FCM/APNs、188以降の文字認識比較入口・イラスト、苦手な風味設定・注意表示は含めない。これらの開発履歴は元ブランチ/PR108等に保全し、今回のソースには取り込まない。

星リストは65f2877、操作表示は9bbf5c4、タイムライン％と星入口はfa1a9f0から選択適用。場所未登録機能は1477fb1から該当機能だけ抽出し、案内の復元と進捗記録は除外。公開版から変わったlibファイル15個が対象機能の許可リストに一致し、ホーム・個人設定・好みのデータ型・カメラ・比較機能・共通の風味判定は基準版と同一であることを確認した。
