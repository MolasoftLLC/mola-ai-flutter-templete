# 利用状況の計測

リリース版でのみ記録します。既存バージョンの過去の操作は復元できません。
管理画面 `https://admin.sakemikke.com/usage` で期間（日本時間、最大90日）・端末・ビルド番号を指定します。

## 計測対象

- ボトムナビ、ホームの検索・最近調べた・おすすめ・タイムライン・もっと見る・再選定
- ホームの3つの酒カード欄が25%以上画面内に見えた回数（ホームの訪問ごとに1回）
- スキャン入口、ログイン・保存上限による停止、カメラ・写真選択、表・裏の送信、候補選択・確定、撮り直し、詳細取得の完了・失敗・中断、メニュー切替・切り抜き
- メニュー撮影・写真選択、読み取り開始・完了・失敗、詳細取得開始・完了・一部失敗・中断、履歴、場所選択、酒詳細
- 名前・産地での検索、検索結果・該当なし、詳細を開く操作
- お酒の保存・お気に入り、場所・感想、購入リンク、X投稿処理、タイムライン投稿の入口
- マップの店舗・お酒・自分のメニュー写真・外部マップ
- マイページの記録・履歴・自分の投稿・アカウント設定・好みの編集・グリッド/リスト・絞り込み
- 最近調べた一覧の並び替え、タイムラインの詳細・うらやま

操作数と完了数は別です。例えば場所の選択を開いた回数から、登録成功を判断しません。
メニューの読み取り完了は酒名が取得できた時点、詳細取得完了は各行の情報取得が一巡した時点です。一部失敗した解析は完了と失敗の双方に含まれます。
解析の段階表は同じ解析IDでの回数です。日付をまたいだ処理では開始と完了が別日に入ります。
ホームのタップ率は「表示したセッションのうち、その欄をタップしたセッション」の割合です。画像と「もっと見る」のどちらのタップも含みます。表示数そのものを分母にはしません。

## 保存と送信

`lib/common/analytics/app_analytics.dart` に実装。匿名のインストールIDとセッションID、イベントUUID、画面・操作・種別、時刻、アプリ版・ビルド番号・OSを送ります。
写真、感想本文、検索語句、酒名、店舗名、緯度経度、広告ID、生のユーザーIDは計測イベントへ含めません。5.0.28（157）以降は操作時点の未ログイン／アカウント／確認不能の区分と、アカウント照合用の用途別ハッシュを保存します。送信時の認証トークンで照合できた同一アカウントは複数端末で重複除外します。操作後のアカウント切替・ログアウト等で照合できないログはインストール単位で別扱いとし、送信時の別人へ付け替えません。旧キューと旧ログからアカウントを推測しません。
利用端末数はインストールID単位です。再インストールや複数端末は別々に数えるため、実人数として扱いません。

30秒または20件で送信。1回50件まで、端末に最大500件・7日間分を保持します。30分以上バックグラウンドにいるとセッションを更新します。
通信失敗時は保存して再送し、受信側はイベントUUIDで重複を防ぎます。アプリの強制終了直前や上限超過の操作は欠落する可能性があるため、課金・利用回数制限の根拠には使いません。

## 配信時

1. サーバーの `20261010060000_add_app_usage_events` マイグレーションと `/api/app-usage/events`、管理画面を反映。
2. アプリのリリース版を配信。開発版では本番の集計を汚さないよう計測を無効化。
3. 実機でホーム・スキャン・メニューを操作し、管理画面の対象ビルドで受信を確認。

サーバーと管理画面の実装: `molasoft-ai-central/docs/app-usage-analytics.md`。

## 5.0.28（157）からの継続・機能別集計

- 日本時間で今期間と指定した過去期間を比較し、アプリ全体・解析全体・メニュー成功・ラベル成功について、期間内ユニーク数、両期間、各期間のみ、重複除外合計、前期間からの継続率を表示します。初回観測／それ以前の利用ありは別の切り口です。
- ログイン済みアカウント、未ログインのインストール、旧ログのインストール、照合不能のインストールを混ぜません。初回観測は保有ログでの初回で、新規ダウンロード・新規登録ではありません。再インストール等の別IDを推測で結合しません。
- メニュー成功は酒名読み取り、ラベル成功はフローの完了です。両方利用した同じ識別単位は解析全体で1です。ラベル成功時に裏ラベル入力あり／なしを記録し、旧ログは種類未計測とします。
- 初回観測日ごとに翌日、7日以内、28日以内の別日再利用と、7日目・28日目の再利用を区別します。窓の最終日が終わるまでは未確定です。最初の成功解析がメニュー／ラベル／同日両方だったコホートから、後日の各機能への再利用も確認できます。
- 名前検索はリクエスト開始、詳細はデータ取得成功、マップ・タイムラインは画面表示を数えます。記録保存はブックマーク状態を端末へ保存できた成功で、サーバー同期完了・解除・自動作成は含みません。旧版の未計測は不明と表示します。
- リリーステストを計測する場合は `--dart-define=USAGE_ANALYTICS_TEST=true` を指定します。フラグは各イベントに保存され、再送後も維持します。通常の開発ビルドは計測無効です。管理画面のテスト除外は既定で有効で、サーバーの設定済みアカウント／インストールと認証カスタムクレームも利用できます。識別不能な過去のテストを除外済みとは表示しません。
- バックエンドの `20261029090000_add_usage_identity_retention` と対応API、独立した管理画面を先に反映してください。既存の有効データは削除しません。ストアのプライバシー申告・審査提出は利用者側で管理します。
