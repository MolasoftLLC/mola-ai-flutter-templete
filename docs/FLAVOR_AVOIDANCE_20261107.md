# 苦手な風味の初版

## 利用者向けの動作

「好きなお酒の傾向」に「熟成・古酒系の香りが苦手」「重い口当たりが苦手」「長い余韻が苦手」を追加。既存の好みと同じ保存経路を使用し、再起動後も復元できる。苦手設定だけの保存・全解除も可能。

商品詳細に、熟成・古酒系の香り／とろり・重厚な口当たり／長い余韻の記載有無と原文を表示。未記載は「不明」とし、風味がないとは扱わない。熟成期間や酒質劣化を認定する機能ではなく、商品タグ・商品説明の明示された香味表現を参照する初版。

メニュー解析は同定後の説明文、ホームおすすめは取得済み候補の登録タグ・説明文を参照し、選択した苦手な風味に該当する商品を後方へ安定移動する。対象商品は非表示にしない。ホームカードに注意文を付け、詳細で根拠を確認できる。数値の相性・六軸チャートは変更しない。

## 判定と取得の制約

- 銘柄名、箱、常温保管、年数、甘辛、旨味だけから推測しない。
- 明示された熟成香、ナッツ等の香り、とろりとした口当たり、長い余韻などに限定。否定・抑制・比較を含む文は保守的に除外する。自然文全般を理解するモデルではないため、表現次第で未検出になる。
- 商品情報の公式性を追加認定しない。引用元は既存登録タグと説明文であり、実測や飲んだ一本の保存状態の判定ではない。
- 苦手設定だけから六軸の中間値を捏造しない。既存の手動・解析プロフィールも変更しない。
- ホームの根拠取得は既存の認証付き `menu-analysis-history/details` に候補IDを一括送信する。ローカルのサーバー実装を読み、既存DBのgetOverviewのみでAI解析を起動しないことを確認済み。失敗は不明扱いで元候補を維持する。本番APIへの呼出しは未実施。
- 初版はすでに選ばれたホーム候補内の並べ替え。全商品からのサーバー再選定や、飲酒記録からの苦手特徴の学習は未実装。
