# ホームのタイムライン下に日本酒の産地マップを追加

2026-10-29の「日本地図のやつを試しに実装して配信」に対応。

## 利用の流れ

- ホームのタイムライン直後に「日本酒を旅する」とドット調の日本地図、地図を開くボタンを配置。
- 地図上の県をタップして、その県を選んだ状態で専用画面を開く。ボタンからは未選択で開く。
- 47都道府県を輪郭から選択でき、一覧からも選べる。沖縄は南西側の離島枠へ配置。
- 選択した県の既存カタログ商品を最大50件取得し、商品名・蔵元名・種別を表示。商品タップから既存の商品詳細へ進み、そちらの保存機能を使える。
- 公開されている店の地図とは別に、蔵元の所在地を基準とする商品の産地検索。県ごとの味の断定・架空の銘柄・件数・訪問済み表示は加えていない。

## データ・通信

- 地図はNatural Earthのadmin-1データから日本の47都道府県を抽出・簡略化し、約45KBで同梱。Natural Earthはpublic domain。元データ・固定コミット・ハッシュは[出典記録](data/japan_sake_map_source_20261029.json)、再生成はtool/generate_japan_sake_map.py。
- 表示用の地図で、離島は一部省略・南西諸島を別位置に配置。境界や海岸線の正確さを要する用途には使わない。
- ホームでの商品API実行なし。県を選んだときだけ、既存のPlaceMapRepository.discoverSakeMasters(prefecture: 正式県名)を使用。バックエンドでは蔵元のprefecture_codeで絞り込む既存実装を確認。
- 画面内で県ごとに取得結果をキャッシュ。素早く選択が変わった場合、古い県のレスポンスを現在の県として表示しない。通信失敗は再読み込み、0件は未収録として区別。
- 新しいAPI・DB書込・本番シード・バックエンド配備・位置情報取得を追加しない。商品詳細と認証は既存の経路を使う。

## 検証

地図の47県と既存県名リストの一致、ホーム表示でAPIを実行しないこと、地図上の選択と遷移、県切替時の遅延応答・キャッシュ、エラー後再試行・0件、小画面/文字1.5倍での沖縄選択を5テストで確認。
